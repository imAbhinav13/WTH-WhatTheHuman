# WTH: What The Human

WTH is a concept-aware comparative retrieval and generation platform that
presents independently grounded perspectives from Science, Advaita Vedanta,
and Samkhya.

## Current status

The project is under active development.

## Technology stack

- Python 3.11
- FastAPI
- Supabase PostgreSQL and pgvector
- Google Gemini embeddings
- Groq generation
